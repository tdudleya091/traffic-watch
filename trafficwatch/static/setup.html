Set up Traffic Watch

Traffic Watch can use free API keys for live traffic (updates every few seconds), or run without any keys: aircraft snapshots about once an hour and no ships. You can change this later with the ⚙ button on the map.

Aircraft — OpenSky Network

Free for personal use.

  1. Create a free account at opensky-network.org.
  2. Log in, open your account page and create an API client.
  3. Copy the client ID and client secret it shows (also in the credentials.json it offers) into the boxes below.

Ships — AISStream.io

Free. There is no keyless source of live ship positions, so ships need this key.

  1. Go to aisstream.io and sign in with GitHub.
  2. Open API Keys and create a key.
  3. Paste the key below.
